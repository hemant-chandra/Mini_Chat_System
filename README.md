# 💬 Mini Chat System

A beginner-friendly chatroom simulation built with Python and Object-Oriented Programming (OOP).

## 📌 Overview

Mini Chat System simulates a group chatroom where users can join and leave rooms, send messages, and view chat history. It demonstrates how Python classes and objects can be used to organize a simple messaging system.

## ✨ Features

- Create and manage users
- Join and leave a chatroom
- Send messages through a chatroom
- Generate unique message IDs
- Store messages in chat history during program execution
- Display previous messages
- Demonstrate Object-Oriented Programming concepts

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Python Lists and Classes

## ⚙️ How to Run

### Prerequisites

Install Python 3 on your computer.

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/hemant-chandra/Mini_Chat_System.git
   ```

2. Open the project directory:

   ```bash
   cd Mini_Chat_System
   ```

3. Run the Python program:

   ```bash
   python Chat_System.py
   ```

   On Windows, you can also try:

   ```bash
   py Chat_System.py
   ```

## ⚠️ Current Limitations

- Runs in the terminal; there is no graphical interface.
- Does not support real-time communication between different computers.
- Messages are stored in memory and are lost when the program exits.
- User authentication and database storage are not implemented.
